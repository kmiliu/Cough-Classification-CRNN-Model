How to run the interactive demo

  1. Download or clone the repo: git clone https://github.com/kmiliu/CoronaHack-Respiratory-Sound-Dataset.git
  2. Place a model file (e.g. crnn_cough.pt) under output/crnn_model_results_7/, or upload it in the web UI.
  3. Create and activate the project's venv and install requirements: 
    python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
  4. Run the demo: 
    streamlit run app.py
# open http://localhost:8501

Shareable package

Use ./scripts/make_shareable_release.sh to create a zip file that excludes datasets and model binaries. This ensures you can share the demo without private data.
